# Pick-One

Pick-One is a small game app that helps friends fairly decide who pays, who goes first, or who takes the penalty.

## Intended users
Groups of friends or classmates who want a fun, fair way to decide something by chance.

## Features
- Main menu to choose a game
- Ladder game
- Spinner
- Dice duel

## Setup and run
Requirements: Python 3.11 or later.

> The commands below will be updated once the project structure is final.

    git clone https://github.com/T1itm/pick-one.git
    cd pick-one
    python3 -m venv .venv
    source .venv/bin/activate    # Windows: .venv\Scripts\activate
    pip install -r requirements.txt
    python3 -m pick_one
